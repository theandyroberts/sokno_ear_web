A small stamped print label — use for section rubrics, "HOT" flags, and category chips. Always condensed caps.

```jsx
<Tag color="rust">Feature Story</Tag>
<Tag color="rust" star>Hot</Tag>
<Tag color="teal" variant="outline" size="sm">Old Sevier</Tag>
<Tag color="gold" star>Sunsphere</Tag>
```

Colors: `rust` (default, editorial emphasis), `teal`, `green`, `ink`, `gold` (rare/special). `variant="outline"` for a quieter inked chip. `size="sm"` for inline metadata. Set `star` to prefix a ★.
