A printed section rubric ("TOP STORIES & EVENTS") flanked by ornamental rules. Opens each section of the one-page weekly scroll.

```jsx
<SectionHeader id="rumors">What We're Hearing</SectionHeader>
<SectionHeader align="left" ornament="star">More Local Stories</SectionHeader>
```

Slab woodtype, uppercase. `align="center"` (default) flanks the title with rules on both sides; `align="left"` puts a short rule before and a long rule after. Ornaments `diamond` / `star` / `flourish`. Give it an `id` to use as an in-page jump target.
